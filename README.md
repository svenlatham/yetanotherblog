# Yet Another Blog — static archive

Migrated from a MariaDB/WordPress dump to Jekyll for GitHub Pages.

- `_posts/` — 696 published posts, permalinks mirror the old `/YYYY/MM/DD/slug/` URLs
- `_pages/` — 9 published pages at their original `/slug/` paths
- `CNAME` — custom domain (www.yetanotherblog.com)

## Images
Original posts reference `https://www.yetanotherblog.com/wp-content/uploads/...`.
Drop the original uploads folder into `wp-content/uploads/` at the repo root to
keep those URLs working. Until then, images load from the live WordPress site (if up).
